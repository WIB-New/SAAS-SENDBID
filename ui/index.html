Sécurité by design

Chaque couche pensée pour la confiance

Conçu pour les documents sensibles — KYC, reçus de paiement — avec une séparation stricte entre contenu public et privé.

Authentification HMAC-SHA256

Chaque requête est signée : X-API-Key + X-Timestamp + X-Signature avec fenêtre de tolérance anti-rejeu. Obligatoire en production.

Validation par magic bytes

Le type MIME est détecté depuis le contenu réel du fichier — jamais depuis l'extension déclarée. Exécutables et scripts rejetés.

URLs signées à TTL court

Accès temporaire aux fichiers sensibles via des liens HMAC expirables — par défaut 60 secondes, auditable à chaque usage.

Purge EXIF systématique

GPS, modèle d'appareil, horodatage : toutes les métadonnées sont supprimées et l'image ré-encodée avant persistance.

Audit trail complet

Chaque accès aux fichiers sensibles est journalisé : utilisateur, rôle, IP, user-agent, action et résultat — en base PostgreSQL.

Observabilité native

Health checks DB + disque, métriques au format Prometheus, X-Request-ID sur chaque réponse pour la traçabilité.

Un client prêt pour Django

Le SDK Python gère la signature HMAC pour vous — trois lignes suffisent.

views.py — Djangostorage_client.py
from django_integration.storage_client import StorageClient

client = StorageClient()

# Upload un avatar → URL publique CDN
res = client.upload_avatar(
    request.FILES["avatar"],
    owner_user_id=str(request.user.id),
)
profile.avatar_url = res["url"]

# URL signée 60s pour un document KYC
link = client.get_file_url(kyc_id, user_id, ttl=60)
